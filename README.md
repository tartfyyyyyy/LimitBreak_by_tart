# LimitBreak_by_tart
LimitBreak is the ultimate universal solution to completely eliminate all forms of performance throttling on Android devices. Whether your device uses thermal-engine, thermald, perfd, mpdecision, or vendor-specific implementations, LimitBreak systematically disables every known throttling mechanism.
**The most advanced, fully encrypted Magisk/KernelSU module for permanently disabling CPU, GPU, and thermal throttling on ANY Android device.**
